# Concepts

This directory stores rationale and design notes for maintainers of this repository.

These files are not the primary execution layer for models.

Models should follow:

- `AGENTS.md`
- `.agents/common/rules.md`
- `.agents/common/context.md`
- workflow scripts
- model-adapter prompts

Use `docs/concepts/` when refining the system, not as the first rule source for task execution.
